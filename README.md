## Кейс 1. Readme для MVC-приложения погоды

### WeatherApp

#### Описание приложения

Приложение показывает погоду для указанного города с помощью WeatherAPI. Данные отображаются на русском языке. Интерфейс состоит из трёх карточек:

1. Погода сейчас
2. Почасовой прогноз с горизонтальной прокруткой
3. Прогноз на 3 дня

#### Стек технологий

+ .NET Framework 4.8 (или совместимая версия)
+ ASP.NET MVC
+ C#
+ Razor Views
+ HttpClient + Newtonsoft.Json для работы с API

#### Установка и запуск

1. Скопируйте проект на локальный компьютер.
2. Откройте файл **.sln** в Visual Studio.
3. Убедитесь, что установлен **.NET Framework 4.8**.
4. Запустите проект (F5) в режиме **IIS Express**.
5. Приложение откроется в браузере.

#### Настройка города

По умолчанию используется город Москва (координаты 55.7558,37.6173).
В **WeatherService.cs** можно изменить город, передав его в параметре **q** в запросе к API:
`var url = $"http://api.weatherapi.com/v1/forecast.json?key={API_KEY}&q={city}&days=3&lang=ru";`

#### Возможные ошибки

+ Если API недоступен или нет интернета, отображается сообщение об ошибке и кнопка **«Повторить»**.
+ Если загрузка длится долго, отображается текст «Загрузка погоды…».

*Примечание: Проект выполнен как тестовое задание. Ознакомиться с проектом можно [по этой ссылке](https://github.com/NikaNGit/WeatherApp)*

## Кейс 2. Инструкция

### Как создать событие в Яндекс.Календаре

**Зачем это нужно**  
Запланировать встречу с автоматическим напоминанием за 15 минут до начала.

**Вам понадобится**
* Браузер с авторизацией в Яндекс (в правом верхнем углу — ваша почта)
* Яндекс.Календарь: перейдите на [calendar.yandex.ru](https://calendar.yandex.ru)

**Пошаговая инструкция**

1. В календаре найдите нужную дату (например, 5 февраля).
2. Кликните левой кнопкой мыши на ячейку времени (например, «15:00») в основном поле календаря.
   → Откроется окно «Новое событие» справа.
3. В поле «Название» введите текст (обязательно!): например, `Собеседование`.
4. Убедитесь, что время установлено правильно:
   - «Начало»: 15:00
   - «Окончание»: 16:00
   *(Если нужно событие «весь день» — поставьте галочку «Весь день» под полями времени)*
5. Опционально: заполните поле «Место» (офис, конференц‑зал, ссылка на видеовстречу) и «Описание» (дополнительная информация для участников).
6. Напоминание включено по умолчанию («За 15 минут»). Если нет — раскройте блок «Напоминание» и выберите из списка.
7. Чтобы пригласить коллег:
   * нажмите «Пригласить участников»;
   * введите email‑адреса (например, `ivanov@company.ru`);
   * выберите уровень доступа:  
     * «Может редактировать» (для организаторов);  
     * «Только просмотр» (для участников).
8. Нажмите синюю кнопку «Создать» внизу окна (справа).

**Что будет после**
- Событие появится в календаре цветной полосой.
- За 15 минут до начала придёт уведомление в браузере и на почту.

**Советы и рекомендации**
* Для повторяющихся событий: в окне «Новое событие» выберите «Повторять» → задайте периодичность (ежедневно, еженедельно и т. д.).
* Для видеовстреч: добавьте ссылку на конференцию в поле «Место» (например, Zoom, Яндекс Телемост).
* Чтобы изменить событие: кликните по нему в календаре → внесите правки → нажмите «Сохранить».
* Чтобы удалить событие: откройте его → нажмите «Удалить» → подтвердите действие.

**Если не получается**
* Окно «Новое событие» не открывается → обновите страницу (Ctrl + F5), проверьте, что вы вошли в нужный аккаунт.
* Не получается пригласить участников → убедитесь, что email‑адреса введены корректно, проверьте настройки доступа к календарю (раздел «Настройки» → «Доступ»).
* Событие не сохраняется → проверьте подключение к интернету, попробуйте другой браузер (Chrome, Firefox, Яндекс Браузер).

**Полезные ссылки**
* [Справка Яндекс Календаря](https://yandex.ru/support/calendar/) — официальная документация.
* [Как настроить уведомления](https://yandex.ru/support/calendar/notifications.html) — инструкция по оповещениям.
* [Управление доступом к календарю](https://yandex.ru/support/calendar/sharing.html) — настройка прав.

## Кейс 4: Инструкция с обработкой ошибок

### Как восстановить доступ к Яндекс.Диску

**Зачем это нужно**  
Вернуть доступ к файлам, если забыли пароль или потеряли устройство с двухфакторной аутентификацией.

**Вам понадобится**
- Почта Яндекс, к которой привязан Диск (`ваше-имя@yandex.ru`)
- Доступ к резервному email или номеру телефона (указанным при регистрации)

#### Пошаговая инструкция

1. Откройте страницу восстановления: [passport.yandex.ru/restoration](https://passport.yandex.ru/restoration)
2. Введите вашу почту Яндекс → нажмите **«Далее»**.
3. Выберите способ восстановления:
   - **«Отправить код на резервный email»** — если помните резервную почту
   - **«Получить SMS»** — если номер телефона активен
4. Введите полученный код в поле → нажмите **«Подтвердить»**.
5. Придумайте **новый пароль** (минимум 8 символов, буквы + цифры) → повторите его → нажмите **«Сохранить»**.
6. Войдите в Яндекс.Диск: [disk.yandex.ru](https://disk.yandex.ru)

#### Если не получается

| Проблема | Решение |
|----------|---------|
| Нет доступа к резервному email / телефону | Нажмите **«Не помню пароль и нет доступа к телефону»** → заполните форму с данными аккаунта (дата регистрации, последние загруженные файлы). Рассмотрение — до 3 дней. |
| Код не приходит | Подождите 2 минуты → нажмите **«Отправить повторно»**. Если не пришёл — проверьте папку «Спам» в резервной почте. |
| Пароль не сохраняется | Убедитесь, что новый пароль отличается от старого и содержит буквы + цифры. |

#### После восстановления

- Смените пароль на всех устройствах (телефон, планшет).
- Включите двухфакторную аутентификацию: **Настройки аккаунта → Безопасность → Двухфакторная аутентификация**.
